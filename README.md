# Рядом

Самостоятельный сайт на React и Vite. Сервер Node.js хранит в MySQL аккаунты, пары, ответы, фото, памятные даты и сессии. ChatGPT для входа не нужен.

## Запуск на этом Mac

В папке с результатами есть файл «Запустить Рядом.command». Дважды щёлкни по нему в Finder. Он запустит локальный MySQL и приложение, затем откроет сайт в браузере. Пока пользуешься сайтом, оставь окно Терминала открытым. База сохраняется в `data/mysql-local/data`, а настройки подключения — в закрытом файле `.env`.

## Запуск на другом компьютере

Нужен Node.js 22.13 или новее и MySQL 8.4. Если MySQL ещё нет, в проекте есть конфигурация для Docker Compose.

1. Скопируй `.env.example` в `.env` и замени `MYSQL_PASSWORD` на свой пароль.
2. Запусти команды из папки проекта:

   ```sh
   docker compose up -d --wait
   npm ci
   npm run dev
   ```

   Если MySQL уже настроен, пропусти команду Docker. Создай в MySQL пустую базу и отдельного пользователя с правами на неё. Впиши параметры подключения в `.env`. Приложение создаст нужные таблицы при запуске.

3. Открой [http://127.0.0.1:5173](http://127.0.0.1:5173). Для проверки с двумя аккаунтами используй два профиля браузера: первый создаёт пару и отправляет автоматически выданный код, второй вводит его в своём аккаунте.

## Перенос из прежней версии с SQLite

Если ты уже пользовалась самостоятельной версией, сохрани старый файл `data/ryadom.sqlite`. Останови обе версии сайта и выполни импорт в пустую базу MySQL:

```sh
npm run db:import-sqlite -- ./data/ryadom.sqlite
```

Команда копирует аккаунты, пары, ответы, фото и даты. Старый файл остаётся у тебя. После переноса нужно снова войти с прежним логином и паролем. Импорт активных сессий и счётчиков попыток входа не нужен.

## Два устройства в одной сети Wi-Fi

1. Останови сайт, закрыв окно Терминала, из которого он запущен.
2. Открой Терминал, введи `HOST=0.0.0.0 ` (с пробелом в конце), перетащи туда файл «Запустить Рядом.command» и нажми Enter.
3. На Mac найди IP-адрес в «Системные настройки» → Wi-Fi → «Подробнее» → TCP/IP. На втором устройстве открой `http://IP-адрес:5173`, например `http://192.168.1.20:5173`. Оба устройства должны быть в одной доверенной сети.

Оба устройства подключаются к одному сайту и одной базе. Для пары заведите разные аккаунты и соедините их кодом. Фото, даты и ответы сохраняются в MySQL и остаются после закрытия сайта. Во время работы новые общие данные подтягиваются примерно раз в 20 секунд.

## Запуск для двоих из разных городов

Размести приложение на одном сервере с доступом к MySQL и HTTPS. Команды запуска:

```sh
npm ci
npm run build
npm start
```

По умолчанию Node.js слушает `127.0.0.1:5173`. Установи `PUBLIC_ORIGIN` в полный HTTPS-адрес сайта и настрой обратный прокси. Переменные `PORT` и `HOST` меняют адрес прослушивания. Если прокси находится на том же сервере и перезаписывает `X-Real-IP` адресом клиента, установи `TRUST_LOCAL_PROXY=1`.

Для удалённой MySQL с TLS включи `MYSQL_TLS=1`. Если провайдер базы выдал сертификат своего центра сертификации, укажи путь в `MYSQL_CA_FILE`. Храни файл `.env` только на сервере. Для данных Docker использует постоянный том `ryadom-mysql`.

Восстановления пароля в приложении пока нет.

## Работа вдвоём через GitHub

Для ручных правок сначала выполни `git pull --ff-only`. После правки сделай коммит и отправь его командой `git push`. Codex после каждой законченной правки делает коммит и отправляет изменения на GitHub по правилам в `AGENTS.md`. Каждый использует свой локальный `.env`; общую базу хранит сервер приложения.
